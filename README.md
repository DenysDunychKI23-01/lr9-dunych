# 🦸‍♂️ Практична робота: Робота з даними у форматі JSON

Повноцінно виконана практична робота з завантаження та виведення JSON-даних у браузер за допомогою JavaScript (XMLHttpRequest & DOM Manipulation)[cite: 29, 30].

---

## 📌 Мета та Завдання роботи

* **Мета:** Набути практичних навиків з отримання та використання даних у форматі JSON із віддаленого сервера[cite: 29].
* **Основні завдання:**
  1. Реалізувати функцію `populateHeader()` для заповнення заголовка сторінки (`<header>`)[cite: 32, 33].
  2. Реалізувати функцію `showHeroes()` для динамічного створення інформаційних карток кожного героя (`<section>` -> `<article>`)[cite: 32, 33].
  3. Не змінювати код HTML та CSS вручну — весь вміст формується динамічно через JavaScript[cite: 33].

---

## ⚙️ Технічна реалізація

### 1. Мережевий запит (XMLHttpRequest)
Використано класичний об'єкт `XMLHttpRequest` для здійснення GET-запиту за адресою `https://semegenkep.github.io/json/example.json`[cite: 30, 31]:
* `request.open('GET', requestURL)`[cite: 31]
* `request.responseType = 'json'`[cite: 31]
* `request.send()`[cite: 31]

### 2. Динамічне заповнення DOM
* **`populateHeader(superHeroes)`**: створює `<h1>` з назвою команди (`squadName`) та `<p>` із містом та роком заснування (`homeTown`, `formed`)[cite: 32, 33].
* **`showHeroes(superHeroes)`**: ітерується по масиву `members` і для кожного героя генерує елемент `<article>`, що містить `<h2>`, текстові параграфи `<p>` та маркований список `<ul>` зі здібностями (`powers`)[cite: 32, 33].
